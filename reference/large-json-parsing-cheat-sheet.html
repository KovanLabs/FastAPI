JSON-array state

before_array → first_or_end → in_element → separator_or_end ↑ │ └──── element_required ←┘ separator_or_end → done

Failure policy

  • Valid object: process and continue.
  • Valid non-object: report not_object and continue.
  • Element exceeds raw-byte cap: reject with record_too_large.
  • Broken JSON structure/UTF-8: reject the JSON document; boundaries are no longer trustworthy.
