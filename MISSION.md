# Mission: Understand This FastAPI Application

## Why
Build enough working knowledge of this repository to explain what each construct in `app/` does, why it is placed there, and safely extend or debug the API without copying patterns blindly.

## Success looks like
- Trace an HTTP request from FastAPI startup through middleware, dependency injection, route handling, validation, and response serialization.
- Explain every executable statement in `app/`, including its purpose and trade-offs.
- Distinguish active application code from examples, unfinished code, and code that is not yet wired into a route.
- Make a small change in the correct layer and know which tests should prove it.

## Constraints
- Teach from this repository's actual code and pinned library versions.
- Prefer plain-language explanations, while retaining the exact Python and FastAPI terminology.
- Break the material into reviewable sections rather than one undifferentiated wall of text.

## Out of scope
- Rewriting or fixing the application unless explicitly requested.
- Explaining every line of the test suite in this lesson.
